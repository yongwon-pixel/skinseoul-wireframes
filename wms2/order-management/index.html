Order Management Dashboard — Changes (spec G + F)

  1. 1Manual Marketing Order Import (M1, confirmed 2026-07-23) — dev team's standard Download Template (.xlsx) → fill in → upload → Preview → set Order Type (Influencer Seeding preset + custom input) and PIC (default = logged-in user, ✎ Custom input allowed — 2026-08-03) → confirm. On confirm (confirmed 2026-08-03): ① each row's country gets its connected carrier auto-assigned (M1b column); countries with no connected carrier show "Not connected — contact the Fulfillment Center" ② if no issues, a green toast "Confirmed" appears top-right. No stock validation (import can come before inbound; Notion G's stock-error item dropped — not surfaced in UI copy) · Once confirmed, orders appear immediately in the RTO Marketing view regardless of stock — G
  2. 2Sample Assignment ON/OFF (redesigned 2026-07-23) — ON modal (M2): target = 2 options, "All new orders in this period" / "Selected orders only" + start datetime (Y/M/D/h) and end or forever; no sample-type selection. Cancel Sample Assignment (M3): select and cancel from the list of current/past assignment periods (overlaps allowed). Even with overlapping periods, exactly 1 sample set per order (no duplicate assignment, confirmed 2026-08-03). Dual-view (confirmed 2026-08-03): during an assignment period, carrier-facing data only appends "(+ sample set)" to the last product name (avoids tax issues), while the internal invoice & picking label mark the sample included and show which sample and how many — internal and carrier see different information — G
  3. 3Bulk Hold Shipment button removed — Hold is handled via Change Status (on-hold) on the order detail page (F); the OMS dashboard stays as the live screen (removed item — no on-screen dot) — cleanup
  4. 4The order list table is identical to the current admin, so it is omitted from the wireframe (no changes, including default columns ↔ Columns toggle). However, imported MKT- marketing order rows get a purple tint + MKT badge + PIC display to visually separate them from regular sales (settlement & volume separation) — G
  5. 5Top-right Comments hub — shared across all screens, includes full comment search — 0. UI 2

Global nav · filter bar (dates · Search · PIC · Status · Order#/Tracking# checkboxes · Country · page size) · Merge Orders · Export/Yun Export · 2,818 total · pagination all stay as in the live screen.
