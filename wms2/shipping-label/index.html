Shipping Labels — Internal invoice redesign (2026-08-03 owner direction)

  1. 1One unified internal invoice, carrier-agnostic — YUN switches from portrait to landscape; both print the same 100×150mm label in landscape (150×100mm). The internal invoice is our own document, so any carrier added later (e.g. FedEx) inherits this exact format with zero changes; carrier labels always stay at each carrier's own default and are never touched — owner 2026-08-03
  2. 2사이즈 column added — value comes from the Order page line-items table's Size column (e.g. 50ml) — owner 2026-08-03
  3. 3로케이션 column added — shown for products with an assigned warehouse location (mono bold, e.g. A-01-07); products without one (JIT sourcing etc.) show “—” — owner 2026-08-03
  4. 4Minimal margins — padding cut to ~2–3mm on all sides so more rows fit per page: the same 9-unit order drops from 2 pages to 1. Corner items keep their positions: order no (top-left) · barcode (top-center) · 총수량 (top-right) · [검수 후 폐기] (bottom-left) · page n/m (bottom-right) — owner 2026-08-03
  5. 5Top strip unchanged in content: PACKING + order number top-left, order barcode top-center, 총수량 top-right — kept from current
  6. 6합계 row added at the bottom of the table — total quantity repeated at the bottom, separate from the top-right 총수량, so the packer can verify without looking back up — owner 2026-08-03
  7. 7Sample set row — when the order has a sample assignment, one amber-tinted row rendered as exactly “sample set” (no type, no per-type qty — v1 rule [G-13]/PD-51); location = sample shelf. Carrier-facing data instead appends “(+ sample set)” to the last product name — G-13
  8. 8YUN carrier label — carrier standard spec reproduced as-is (routing · destination · tracking barcode · SHIP TO · Tel · SKINSEOUL_no.); unchangeable — actual print
  9. 9DELEO carrier label — DELEO default kept; their layout truncates to 3 items + “5 more”, which is fine because full detail lives on the internal invoice — actual print

Font sizes are calibrated from the photographed prints at the mockup's 5px/mm scale — DELEO internal body ≈3.6mm → 18px · title ≈5.5mm → 28px · 총수량 ≈4.4mm → 22px · YUN internal body ≈4mm → 20px; the unified proposal uses ≥ the current DELEO sizes (body 19px, qty 21px bold). The two “Current” tabs and both carrier tabs reproduce the actual prints photographed on 2026-08-03. Only the ★ Unified tab is a proposal. Label content stays Korean (product names, 총수량/합계/검수 후 폐기) — printed labels are data, not admin UI [G-6]. An earlier Plan-B concept (BC last-4-digits column, SKU column, brand bolding on the label) is superseded by this owner direction and kept only in git history; the BC column can be revived as an option if wanted.
