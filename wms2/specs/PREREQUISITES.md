# WMS 2.0 — Prerequisites

> What has to be in place **before or alongside** the build. Every item here is something the developer cannot resolve in code: hardware, external accounts, master data, or a decision only SkinSeoul can make.
>
> Every row cites the spec that requires it. Nothing on this page is inferred — where a spec fixes a policy but names no mechanism, the row says so explicitly.
>
> **Owner column:** *SkinSeoul* = we provide it. *Joint* = SkinSeoul provides the thing, the developer integrates it.

## Notes on scope of this list

- **Items deliberately excluded because the developer owns them:** the marketing-order import template `.xlsx` is "produced and versioned by the dev team" (`order-management.md` §6), so it is not a SkinSeoul prerequisite even though its column set is specified.
- **Items that look like prerequisites but are already decided:** the operating timezone is fixed at **KST (Asia/Seoul)** by `[G-16]` for every screen and every printed artefact — it only needs configuring once, system-wide. The permission model is decided too: v1 is a single admin role `[G-15]`, so no role matrix is owed before build.
- **The Procurement Hub is excluded from this spec set entirely** (owner decision, 2026-08-02) — no link, no reference, no dependency. Item D1's costing read is the single exception.
- **No Closing sheet integration is required.** The SS Daily Shipping Status spreadsheet was retired outright; Closing History replaces it wholesale.
