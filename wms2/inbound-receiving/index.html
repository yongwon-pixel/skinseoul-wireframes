State 1 신규 주석 — 내부 입고 스캔 (입고 진행 중)

  1. 1송장 스캔 자동 분기 — View Orders 검색창에 스캔된 송장이 입고 요청(I) 건이면 고객 오더 화면이 아니라 이 화면으로 전환. 고객 오더(입고→즉시 출고)와 내부 입고(재고 편입)를 뷰 차원에서 분리 — I + C 검색
  2. 2내부 입고 구분 배너 — 보라 테두리 대형 배너로 "고객 오더 아님·출고 없음"을 즉시 인지. Inbound No.·채널 배지·Supplier·신청자·예상 입고일 + 요청 리스트 바로가기 — 신규
  3. 3진행 타일 — 요청 수량 vs 입고 확인(스캔 누적) vs 남은 수량, SKU 단위 완료 카운트 — 신규
  4. 4제품 바코드 연속 스캔 — 스캔마다 해당 SKU 입고 Qty +1, 커서 자동 복귀. 요청에 없는 제품 스캔 시 경고음(오배송 감지) — C 스캔 규약
  5. 5요청 vs 입고 대조 테이블 — SKU No./Brand/Product Name은 입고 요청 신청값 그대로(시트 열 정합) — I
  6. 6입고 Qty = 스캔 누적 + 직접 보정 가능(박스 단위 대량 입고 시 수기 입력) — 신규
  7. 7Location = Inventory 편입 위치 — 기존 재고 SKU면 현 로케이션 자동 제안(SKU당 1개 원칙), 신규 SKU는 지정 입력 — E 로케이션 규약
  8. 8전량 입고 확정 — 요청 수량과 입고 수량이 전 SKU 정확히 일치해야 활성(마감 페이지와 동일한 일치 게이팅). 불일치 상태에서는 부분 입고 저장(M1)으로 사유를 남기고 이어서 처리. 초과 스캔은 경고 — 신규

동작 규칙(화면 밖): 확정 시 ① Inventory(Current Stocks)에 로케이션과 함께 반영 ② 입고 요청 리스트 상태 발송 → 입고완료 자동 전환 ③ Received Date·Carrier 자동 기록(시트 연동 대비) ④ 검색창 포커스 복귀로 다음 송장 스캔. 고객 오더 화면(Inbound/Outbound 버튼)과 달리 이 화면에는 Outbound가 존재하지 않음.
